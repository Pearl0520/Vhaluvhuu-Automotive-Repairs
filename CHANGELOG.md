# Changelog

All notable changes to the Vhaluvhuu Automotive Repairs website are documented here.

## [2026-11-02]

### Added

- Added WhatsApp contact buttons across the website and a homepage callback request dialog that opens WhatsApp with a prefilled message.
- Added a homepage FAQ section and reusable SVG icons for form fields.

### Changed

- Refreshed the responsive styling and layout of the website's contact and enquiry forms.

## [2026-10-25]

### Added

- Added [js/main.js](js/main.js) to provide interactive JavaScript features across the website.
- Added a homepage welcome popup that closes after 15 seconds, a live local date and time display, and the homepage "Click on me" interaction.
- Added client-side form validation, prevention of past booking dates, and keyboard-accessible image enlargement.

### Changed

- Updated [README.md](README.md) with Part 3 JavaScript enhancement details and the current project file structure.

## [2026-09-17]

### Added

- Added this project [changelog](CHANGELOG.md).
- Added responsive content image styling in [css/style.css](css/style.css).

### Changed

- Standardized service content images with responsive square frames while preserving their full contents.
- Corrected the homepage stylesheet path in [index.html](index.html) to `css/style.css`.
- Updated the project file list and deployment notes in [README.md](README.md).
- Improved spelling, capitalization, and wording across [index.html](index.html), [about.html](about.html), [services.html](services.html), [enquiry.html](enquiry.html), and [contact.html](contact.html).
- Added meaningful alternative text to service images in [services.html](services.html).
- Moved the homepage services link outside the unordered list in [index.html](index.html) for valid markup.
- Standardized the services call-to-action section markup in [services.html](services.html).

### Fixed

- Restored the missing email input in the form in [enquiry.html](enquiry.html).
- Replaced invalid `lable`, `setion`, and incorrectly capitalized section elements in [index.html](index.html), [services.html](services.html), [enquiry.html](enquiry.html), and [contact.html](contact.html).
- Removed the duplicate nested section in [contact.html](contact.html).
